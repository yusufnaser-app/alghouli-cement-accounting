## خطوة إلزامية قبل أول بناء: إضافة خط عربي لـ PDF

حزمة `pdf` تحتاج ملف خط TTF عربي حتى تُكتب الحروف متصلة بشكل صحيح. نزّل خطًا
مجانيًا (مثل Noto Naskh Arabic أو Cairo) وضعه في:

```
assets/fonts/NotoNaskhArabic-Regular.ttf
```

ثم أضف في `pubspec.yaml` ضمن `flutter:`:
```yaml
  fonts:
    - family: NotoNaskhArabic
      fonts:
        - asset: assets/fonts/NotoNaskhArabic-Regular.ttf
```
بدون هذه الخطوة، يعمل التطبيق لكن نصوص PDF العربية تظهر بحروف غير متصلة (خط
احتياطي)، وستظهر رسالة تنبيه صريحة عند التصدير تذكّرك بذلك بدل فشل صامت.
